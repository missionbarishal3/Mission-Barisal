## 🛡️ Imunify360 Bot Protection

Remote server `Imunify360` দিয়ে protected:
- `curl/terminal` → ব্লক হয়
- `Browser` → পাস হয় (JavaScript challenge solve হয়)
- `VS Code Extension` → পাস হয় (browser-like headers পাঠায়)

### Solution:
- VS Code extension সরাসরি `b.missionbarisal.site` এ কাজ করবে
- Terminal থেকে test করতে browser `User-Agent` ব্যবহার করুন
